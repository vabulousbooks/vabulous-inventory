# Vabulous Inventory Prototype

A mobile-friendly Vite + React prototype for Vabulous Books.

## Features
- SKU generation using `VB-YYYYMMDD-###`
- Inventory fields matching the existing spreadsheet
- Local browser storage
- Six-card print queue
- Letter-size 2 × 3 print sheet with 4.25 × 3.67 inch cards
- CSV export

## Deploy
Upload all files in this folder to the root of the GitHub repository, then import the repository into Vercel with the Vite preset.
