VABULOUS BOOKS INVENTORY — PROTOTYPE 1

HOW TO TEST
1. Open index.html in Safari or Chrome on a computer.
2. To test on an iPhone, place the folder on a simple web host or open it through a local web server. Camera scanning generally requires HTTPS.
3. Add books. Records are saved in that browser's local storage.
4. After six books, open Print Queue and print on the 2-column × 3-row perforated sheet.
5. Use Export CSV regularly. The CSV columns match the uploaded Vabulous Books Inventory spreadsheet.

IMPORTANT
- This prototype does not yet write directly to Google Sheets.
- Data can be lost if browser data is cleared.
- ISBN camera scanning depends on browser support for BarcodeDetector.
- The printed cards are set to 4.25 in × 3.6667 in, six per US Letter page, with zero page margins.
- In the print dialog, choose Actual Size / 100% scale and disable browser headers and footers.
